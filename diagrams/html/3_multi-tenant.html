Como ler este diagrama

requireCompany(user.id) é o único lugar que resolve "qual empresa é essa" — depois disso companyId é só um valor passado por parâmetro.
Compare a assinatura correta com a errada: findAllByCompany(companyId) ✅ vs. findAll() ❌.
Por que importa: se um repositório esquecer o WHERE company_id, a query retorna dados de todas as agências — um vazamento real de dados entre clientes do SaaS, do tipo que não aparece testando com um único usuário.
Toda action começa com requireUser() → requireCompany(user.id) — convenção fixa do projeto, sem exceção.
