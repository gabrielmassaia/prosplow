Como ler este diagrama

A seta implementa é a inversão de dependência (DIP): DrizzleCampaignRepository e OverpassGeoService apontam para a interface — o use case só enxerga ICampaignRepository/IGeoService.
app/ nunca fala com db diretamente. Se aparecer db.query… dentro de app/actions/, é violação de arquitetura.
Trocar Overpass por outro provider de geo significa criar uma nova classe em infrastructure/services/ e mudar uma linha na action — nada em use-cases/ muda (OCP).
companyId sempre explícito nos parâmetros — nunca contexto global. Ver 3_multi-tenant.
