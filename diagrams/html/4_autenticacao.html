Como ler este diagrama

A transação no signup é o ponto mais importante: sem db.transaction(), um INSERT company_members que falhar deixaria uma empresa órfã, sem dono.
users.id é text (gerado pelo Better Auth) — companies.owner_id referencia esse campo como texto, nunca uuid.
O proxy hoje só checa se o cookie existe — a validade real da sessão é checada depois, em requireUser(). A Aula 4 move essa validação para o próprio proxy.
role: "owner" é o único valor usado hoje — member existe no schema para um fluxo futuro de convite de equipe, fora do escopo atual.
