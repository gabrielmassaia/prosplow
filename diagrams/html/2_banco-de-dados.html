Como ler este diagrama

Toda tabela de negócio pendura em companies. Se você adicionar uma tabela nova e ela não tiver company_id, algo está errado no design.
prospecting_leads → crm_leads é 1:1 nullable — um lead de prospecção pode virar (ou não) um lead do funil comercial.
lead_activities tem duas FKs para funnel_stages (from/to), ambas nullable — a primeira atividade de um lead não tem "de onde".
users.id é text (Better Auth gera IDs como string) enquanto o resto do schema usa uuid — nunca referenciar owner_id/created_by como uuid.
